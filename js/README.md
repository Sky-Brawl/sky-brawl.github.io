# โค้ดเกม Sky Brawl (โฟลเดอร์ `js/`)

ตั้งแต่เวอร์ชัน 1.6.0 เกมแยกจาก `index.html` ไฟล์เดียวออกเป็นไฟล์ย่อยตามหัวข้อ **โค้ดข้างในเหมือนเดิมทุกบรรทัด** แค่ตัดแบ่งไฟล์

## กฎสำคัญ 3 ข้อ

1. **ทุกไฟล์ใช้ตัวแปรร่วมกัน** (ไม่มี `import`/`export`) ไฟล์หลังเรียกใช้ของจากไฟล์ก่อนได้เลย
2. **ลำดับการโหลดสำคัญ** ลำดับอยู่ในแท็ก `<script>` ท้าย `index.html` ห้ามสลับ ถ้าโค้ดที่ทำงานทันทีตอนโหลด (ไม่ได้อยู่ในฟังก์ชัน) เรียกฟังก์ชันจากไฟล์ที่โหลดทีหลัง เกมจะพัง (`... is not defined`) ให้ย้ายฟังก์ชันนั้นไปไว้ไฟล์ที่โหลดก่อน
3. **ทุกครั้งที่อัปเดตบน GitHub ให้เปลี่ยนเลข `?v=` ในทุกแท็ก `<script>` และ `<link>` ของ `index.html`** (เช่น `1.6.0` → `1.6.1`) ไม่อย่างนั้นผู้เล่นบางคนจะได้ไฟล์เก่าจากแคชปนกับไฟล์ใหม่

## งานที่ทำบ่อย แก้ไฟล์ไหน

| อยากทำ | แก้ไฟล์ |
|---|---|
| เพิ่ม/แก้อาชีพ | `moves.js` (ท่า, สกิล, คอมโบ, ระยะ) + `classes.js` (หน้าตาชุด **ต่อท้าย `OUTFITS` เท่านั้น**) + `weapons.js` (อาวุธในมือ) + `customize.js` (`CLASS_META` แนว/ความยาก) + `../config.js` |
| อาชีพแปลงร่าง | เพิ่มที่ `FORM_INFO` ใน `moves.js` + ชิ้นส่วนร่างใน `forms.js` |
| สกิลที่ยิงกระสุน / เรียกของ | `projectiles.js` (กระสุน, `useSkill`) · `skills.js` (วงเวทที่พื้น, สถานะ) · `summons.js` (ตัวที่อัญเชิญ) |
| เพิ่มด่าน | สร้างไฟล์ใหม่ใน `stages/` + ลงทะเบียนใน `stages/registry.js` + เพิ่มแท็ก `<script>` ใน `index.html` (ก่อน `stages/registry.js`) + การ์ดในเมนูของ `index.html` |
| ปรับตัวเลขโดยไม่แตะโค้ด | `../config.js` |
| หน้าตาเมนู / ปุ่ม / สี | `../style.css` (หน้าตา) และ `../index.html` (โครงหน้าเว็บ) |
| สมองบอท | `bots.js` |
| ออนไลน์ | `relay.js` (หลัก), `online.js`, `online-ui.js` |
| บัญชี / เลเวล / รางวัลรายวัน | `account.js` |
| ปุ่มบนมือถือ | `touch.js` + `../style.css` |

## ทดสอบ

ตัวแปรของเกมเรียกจาก Console ของเบราว์เซอร์ได้ตรงๆ เช่น `G.fighters`, `startOffline('solo', {n: 8})`, `tick()` ไม่ต้องเติม hook แบบเดิม (`window.__SB`) อีกแล้ว

ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (เปิดไฟล์ตรงๆ แบบ `file://` จะโหลด `config.js` ได้ แต่บางเบราว์เซอร์บล็อกส่วนอื่น):

```bash
python -m http.server 8000
```
