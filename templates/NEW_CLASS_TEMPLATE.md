## 2. หน้าตา

ตัวละครในเกมเป็น **บล็อกจิบิ** (หัวโต ตัวเป็นกล่อง) เขียนบรรยายให้เห็นภาพก็พอ

| หัวข้อ | กรอกตรงนี้ | คำอธิบาย |
|---|---|---|
| สีชุดหลัก | | ชื่อสีหรือรหัสสี เช่น `ดำอมม่วง` หรือ `#1d1424` |
| สีรอง / ลวดลาย | | เช่น ขอบทอง, ผ้าคาดเอวแดง |
| ของบนหัว | | หมวก / หมวกเกราะ / ฮู้ด / หน้ากาก · ถ้ามี จะใช้แทนของบนหัวที่ผู้เล่นเลือก |
| ซ่อนผมไหม | | ใช่ / ไม่ (เช่น ใส่ฮู้ดคลุมทั้งหัว = ซ่อน) |
| อาวุธในมือ | | เช่น เคียว, หอก, คทา, มือเปล่า |
| ของประดับอื่น | | เช่น ผ้าคลุม, ปีก, หาง, ไฟรอบตัว |
| รูปอ้างอิง | | แนบรูปหรือวาดเองได้ (ไม่บังคับ) |

## 4. สกิลอาชีพ (ปุ่ม E)

| หัวข้อ | กรอกตรงนี้ | คำอธิบาย |
|---|---|---|
| ชื่อสกิล | | เช่น `อัญเชิญโครงกระดูกยักษ์` |
| รูปแบบ | | พุ่งชน · ยิงกระสุน · ระเบิดวงรอบตัว · วงที่พื้นตรงศัตรู · อัญเชิญตัวช่วย · แปลงร่าง · ฮีล/บัพ · วาร์ป · อื่นๆ |
| เล็งยังไง | | ข้างหน้า / ศัตรูที่ใกล้ที่สุด / ตัวเอง / เพื่อนเลือดน้อย |
| อธิบายสกิลแบบเต็ม | | เกิดอะไรขึ้นตั้งแต่กดจนจบ ใครโดน โดนแล้วเป็นอะไร |

**ตัวเลข** (ไม่แน่ใจให้เว้นว่าง ทีมจะปรับสมดุลให้)

| ค่า | กรอกตรงนี้ | ช่วงที่แนะนำ |
|---|---|---|

| ดาเมจ | | 8–30 ต่อครั้ง (เลือดเต็ม 100) · ถ้าโดนหลายครั้ง ให้ใส่ "ต่อครั้ง" |
| แรงกระเด็น | | 2 (แทบไม่ขยับ) – 13 (ปลิว) |
| รัศมี / ระยะ (ช่อง) | | วงรอบตัว 3–4 · ยิงไกล 8–14 |
| สถานะที่ทำให้ศัตรู | | มึน / แช่แข็ง / ช็อต / ไฟไหม้ / ไม่มี · นานกี่วินาที (1–3) |
| ทะลุการกันไหม | | ใช่ / ไม่ |
| ฮีล (ถ้ามี) | | เท่าไร ให้ใคร |
| อยู่นานกี่วินาที (อัญเชิญ / แปลงร่าง / บัพ) | | 6–20 |
| เสียพลังตัวเองไหม | | เช่น เสียพลัง 8 แลกพลังโจมตี |

## 7. ตั้งค่าใน `config.js` (ทีมพัฒนาเติม)

```js
// ในหัวข้อ classes:
    <id>:       true,   // <ชื่อไทย> (<คำโปรยสั้นๆ>)
// ในหัวข้อ skills:
    <id>:       { cd: 8, dmg: 12, kb: 6 },   // <ชื่อไทย> · <ชื่อสกิล>: <คำอธิบายค่าพิเศษ>
```

## ✅ รายการตรวจสำหรับผู้พัฒนา (ตอนใส่อาชีพนี้ลงเกม)

ทุกอย่างอยู่ใน `index.html` เว้นแต่จะบอกไว้ ดูรายละเอียดเพิ่มใน `HANDOFF.md`

- [ ] `OUTFITS` เพิ่ม `<id>:{name, body, head?, noHair?, build(h, t){…}}` **ต่อท้ายสุดเท่านั้น** (ลำดับใช้ใน `encLook` ถ้าแทรกกลาง ชุดของผู้เล่นออนไลน์จะเพี้ยน)
- [ ] `MOVES` คอมโบ 3 ท่า (`xx1`–`xx3`) + สกิล `sk_<id>` (`skill:true`, startup / active / recovery, dmg, kb, `snd`)
- [ ] `CLASS_COMBO.<id>` = ท่าแรกของคอมโบ · `CLASS_REACH.<id>` = ระยะตี · สายยิงเพิ่ม `CLASS_STOP.<id>`
- [ ] `SKILL_INFO.<id>` = `{cd (เฟรม = วินาที×60), range, desc}`
- [ ] `CLASS_META.<id>` = `[แนว, ความยาก]` (`melee` / `ranged` / `magic` / `support` / `special`, 1–3)
- [ ] โค้ดสกิลพิเศษ (กระสุนใหม่, `G.zones`, ตัวอัญเชิญ, แปลงร่าง) + ให้ **guest ออนไลน์เห็นเอฟเฟกต์** ด้วย (ข้อมูลใน snapshot)
- [ ] `applyConfig` อ่านค่าจาก `config.js` (ค่าคงที่ต้องประกาศก่อน `applyConfig` ทำงาน)
- [ ] `config.js`: เพิ่มในหัวข้อ `classes` และ `skills` พร้อมคอมเมนต์ภาษาไทย
- [ ] บอทใช้สกิลถูกจังหวะ (ระยะ / เงื่อนไข)
- [ ] ทดสอบ: เล่นกับบอท · 2 คนเครื่องเดียว · ออนไลน์ (host + guest เห็นเหมือนกัน) · มือถือแนวตั้ง/แนวนอน · รูปการ์ดในหน้าเลือกอาชีพขึ้นถูก
- [ ] อัปเดต `HANDOFF.md`, `DEVLOG.md` (ขยับเวอร์ชัน MINOR) และจำนวนอาชีพใน `README.md` / ภาพโปรโมต
